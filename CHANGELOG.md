## 1.0.0 — 2026-10-15

First complete release for independent still-image IIIF Presentation 2.1/3.0 migration review.

- Compare descriptive languages and repeated values, rights, links, stable identities, page order, ranges, painting content and Image API service versions, with original JSON pointers and source hashes.
- Declare role-scoped URI rewrites, inspect their effects, and record intentional changes with evidence-bound reasons. Stale decisions and unsupported coverage prevent an all-clear.
- Review files or pasted text in a responsive local browser workbench, inspect original evidence, navigate by keyboard, and export portable policy and JSON/CSV/scriptless HTML reports.
- Audit explicit paired corpora with optional directory inventories, preserve errors for every attempted pair, and integrate documented exit codes into CI.
- Save an explicitly selected remote snapshot with version negotiation, bounded response/redirect/timeout handling and exact UTF-8 text preservation.
- Install a bundled CLI without registry runtime dependencies, or run the downloadable static workbench locally.

The supported profile and exclusions are documented. A pass is not proof of conformance, image equivalence, legal correctness, link availability or viewer rendering. Public research supports the workflow gap; actual practitioner adoption has not been established.
