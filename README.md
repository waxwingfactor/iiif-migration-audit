# IIIF Migration Audit

Independent preservation checks for digital-library engineers migrating IIIF manifests or replacing their manifest generator.

**Under active development.** The first release will compare independently generated Presentation 2.1 and 3.0 manifests, identify meaningful loss, and produce traceable reviewer and CI reports. It is a comparison tool, complementary to the official IIIF conformance validator.

Research, supported scope, architecture decisions, and release criteria will be published alongside the implementation. No production-readiness claim is made by this initial repository seed.
